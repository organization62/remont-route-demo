# Начните отсюда

Спасибо за покупку Remont Route.

## 1. Откройте сайт

Откройте файл `index.html` в браузере.

## 2. Откройте админку

На главной странице нажмите кнопку `Админка` или откройте файл `admin.html`.

## 3. Замените данные

В админке можно поменять:

- название компании;
- город;
- телефон;
- главный заголовок;
- стиль оформления;
- услуги и цены;
- объекты портфолио;
- фото главного экрана;
- фото “до / после”;
- фото объектов.

Для фото нажмите `Выбрать фото`, выберите изображение на компьютере и сохраните изменения.

## 4. Проверьте заявки

Откройте `leads.html`. Там отображаются тестовые заявки с сайта и доступен экспорт CSV.

## 5. Прочитайте инструкцию

Подробности находятся в `INSTALL.md`.

Перед публикацией обязательно проверьте юридические страницы, контакты, цены, изображения, аналитику и работу формы заявки.
