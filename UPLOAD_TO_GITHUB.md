# Как обновить демо на GitHub Pages

Эта папка содержит чистую версию сайта для загрузки в репозиторий GitHub Pages.

## Что загрузить

Загрузите в репозиторий все файлы и папку `assets` из этой папки:

- `index.html`
- `styles.css`
- `script.js`
- `data.js`
- все `.html` страницы
- папку `assets`
- инструкции `.md`

## Куда загружать

Репозиторий демо:

`organization62/remont-route-demo`

Публичная ссылка после публикации:

`https://organization62.github.io/remont-route-demo/`

## Порядок действий

1. Откройте репозиторий на GitHub.
2. Перейдите на вкладку `Code`.
3. Нажмите `Add file`.
4. Выберите `Upload files`.
5. Перетащите содержимое этой папки в окно загрузки.
6. Дождитесь, пока файлы загрузятся.
7. Внизу нажмите зеленую кнопку `Commit changes`.
8. Подождите 1-3 минуты.
9. Откройте ссылку демо и обновите страницу через `Ctrl + F5`.

## Важно

На GitHub нужно загружать именно содержимое папки, а не саму папку `github-pages-upload-v0.8.7`.

Если GitHub не дает перетащить папку `assets`, откройте ее и загрузите изображения отдельно в папку `assets` в репозитории.
