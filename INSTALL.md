# Установка шаблона Контур Строй

## Быстрый просмотр

Откройте файл `index.html` в браузере.

## Основные страницы

- `index.html` — главная страница.
- `admin.html` — демо-админка для редактирования контента.
- `leads.html` — демо-CRM со списком заявок.
- `services.html` — список SEO-страниц услуг.
- `sell.html` — страница продажи шаблона.
- `guide.html` — инструкция покупателю.
- `CLIENT_GUIDE.md` — подробная инструкция для клиента.

## Как редактировать

1. Откройте `admin.html`.
2. Измените название, телефон, город, стиль, тексты, пакеты, объекты и изображения.
3. Нажмите `Сохранить изменения`.
4. Вернитесь на `index.html`.

Демо-админка сохраняет данные в браузере через `localStorage`. Это удобно для настройки и показа, но не является полноценной онлайн-админкой.

Для постоянной админки с логином, базой данных и доступом с разных устройств можно подключить CMS/backend. Для реальных заявок можно подключить email, Telegram, Google Sheets или CRM.

## Как заменить изображения

В демо-админке есть два способа.

Способ 1:

1. Откройте `admin.html`.
2. Нажмите `Выбрать фото`.
3. Выберите изображение на компьютере.
4. Нажмите `Сохранить изменения`.

Способ 2:

1. Положите новые изображения в папку `assets`.
2. В админке укажите путь, например `assets/my-project.jpg`.
3. Сохраните изменения.

Первый способ удобнее для демонстрации. Второй способ лучше подходит для подготовки аккуратного комплекта файлов.

- GitHub Pages;
- Timeweb;
- Reg.ru;

- любой обычный хостинг для HTML/CSS/JS.

Проверьте:

- реальные контакты;
- юридические страницы;
- согласие под формами;
- аналитику;
- работу формы заявки;
- изображения;
- цены;
- ссылки на мессенджеры;
- мета-заголовки и описания страниц.
