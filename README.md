# Remont Route

Демо-шаблон сайта для компании по ремонту квартир в России.

## Что внутри

- интерактивный калькулятор стоимости ремонта;
- блок маршрута проекта;
- визуальный модуль "до / после";
- пакеты услуг;
- карточки объектов;
- форма заявки с согласием на обработку персональных данных;
- простая встроенная панель редактирования;
- отдельная демо-админка `admin.html`;
- три визуальных пресета оформления;
- инструкция покупателю `guide.html`;
- страница продажи `sell.html`;
- расширенная страница продажи с FAQ, сравнением тарифов и блоком “что можно менять без кода”;
- управление изображениями hero, до/после и портфолио;
- демо-CRM `leads.html` с экспортом заявок в CSV;
- SEO-страницы услуг: `services.html`, `renovation-turnkey.html`, `bathroom-renovation.html`, `kitchen-renovation.html`, `new-build-renovation.html`, `secondary-renovation.html`, `prices.html`;
- упаковочные документы: `LICENSE.txt`, `INSTALL.md`, `PRODUCT.md`, `CHANGELOG.md`, `SUPPORT.md`;
- быстрый старт: `START_HERE.md`;
- экспорт контента в JSON для будущей админки или CMS.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта.

## Как редактировать

На странице нажмите кнопку `Редактировать` в правом нижнем углу. Можно изменить название, город, телефон, главный заголовок, описание, CTA и заголовок формы.

Кнопка `Сохранить` сохраняет изменения в браузере. Кнопка `Экспорт JSON` скачивает файл с контентом, который позже можно использовать в CMS или настоящей админке.

Для более полного управления откройте `admin.html`. Там можно менять основные тексты, цифры доверия, пакеты ремонта и объекты портфолио.

## Как продавать

Можно упаковать шаблон в три тарифа:

- Lite: статический сайт, инструкция и редактирование через демо-админку.
- Pro: установка на хостинг, замена контента и подключение форм заявок.
- Business: Pro плюс настройка домена, Метрики, юридических страниц и базовой SEO-структуры.
